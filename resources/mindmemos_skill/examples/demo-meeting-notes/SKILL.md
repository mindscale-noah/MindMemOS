# Meeting Notes to Actions

Separate explicit decisions from proposals and unresolved questions. Preserve disagreement when the notes do not establish a resolution.

For each action item, include its owner, deliverable, and deadline only when supplied. Mark missing fields as unassigned or unspecified. Resolve relative dates only when the meeting date and relevant timezone are known; otherwise preserve the original wording.

Use [the minutes template](assets/minutes-template.md). [The sample notes](references/sample-notes.md) provide practice input containing both a decision and an unresolved question.

Return a draft in the user's language. Do not send messages, create calendar events, or assign external tasks unless the user requests those actions.
