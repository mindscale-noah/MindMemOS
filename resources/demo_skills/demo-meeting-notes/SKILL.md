# 会议纪要整理

根据用户提供的会议记录生成中文纪要。

1. 阅读全部记录，区分已作出的决策、建议和未解决的问题。
2. 用三句话以内说明会议主题和主要结论。
3. 按 `references/output-template.md` 输出决策和行动项。
4. 只使用记录中出现的负责人和日期；缺失时写“待确认”。
5. 保留意见分歧和依赖关系，不把讨论中的提议写成最终决策。
6. 输出前检查每个行动项是否有具体动作，是否能从原记录找到依据。
