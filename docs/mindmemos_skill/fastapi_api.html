MindMemOS Skill API

由当前服务的 OpenAPI 生成。请求约束如下；结构化写入中的嵌套类型见文末完整 Schema。

项目身份由服务认证确定。任务受理返回 202；只有 succeeded 状态的 result 表示已完成。
