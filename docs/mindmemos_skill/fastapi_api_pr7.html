本地默认服务

python -m mindmemos_skill.api.entries.fastapi --home /path/to/workspace --port 8000

本地模式使用工作区数据库及其持久化的项目 ID；默认只配置 repository pipeline。图管理操作还需要在该工作区的 service.yaml 中配置 management_pipelines，保存后重启服务。

显式服务配置

python -m mindmemos_skill.api.entries.fastapi --config /path/to/service.yaml --project-id my-project --port 8000

显式配置需在启动时使用 --project-id 绑定图路由的项目。省略时，/graphs/* 会返回 503。--config 与 --home 不能同时使用。默认监听 127.0.0.1，可用 --host 改变地址。

服务启动前显式初始化存储，退出时关闭服务资源。运行中的 FastAPI 还提供 /docs、/redoc 和 /openapi.json；本文件可离线查看。

访问边界：独立 FastAPI 入口自身没有认证中间件。项目 ID 是数据范围，不是身份凭证。若要在非本机地址提供服务，应在入口层配置认证和访问限制。

调用约定

  • 除 GET /health 外，业务接口均为 POST，请求体和成功响应通常为 JSON。
  • Skill 仓库接口的 project_id：本地绑定服务可省略；显式配置的服务需在请求体提供。它不构成授权证明。
  • 图接口的 project_id 由服务启动参数绑定；请求体可省略，若提供不同值会返回 422。graph_id 必填。
  • pipeline 是已配置的管理流程名称；只有一个管理流程时可省略。默认本地配置没有管理流程，图业务操作会返回 501。
  • version_ids 是完整成员集合：键是图内成员 ID，值是仓库中精确且不可变的版本 ID。build、upsert 和 remove 都要求提交最终完整集合。
  • 写图请求的 publication.expected_revision 是当前 head 的预期 revision；首次发布为 0。idempotency_key 用于安全重试，提交后可通过 /graphs/published-result 查询。
  • source 若传字符串路径，指的是服务端本地目录或 SKILL.md，不是调用方机器上的路径；也可传完整 SkillSnapshot。

请求示例

以下图示例假定服务已绑定项目并配置一个管理流程；示例版本 ID、图 ID 和任务内容需替换为实际值。自动 Scene 提取还要求配置相应模型。

1. 查询 Skill 列表

curl -sS http://127.0.0.1:8000/skills/list \
  -H 'Content-Type: application/json' \
  -d '{"project_id":"my-project","limit":20,"offset":0}'

2. 预览图成员

curl -sS http://127.0.0.1:8000/graphs/preview \
  -H 'Content-Type: application/json' \
  -d '{"graph_id":"team-skills","version_ids":{"csv":"version-001"}}'

3. 首次发布图

curl -sS http://127.0.0.1:8000/graphs/build \
  -H 'Content-Type: application/json' \
  -d '{"graph_id":"team-skills","version_ids":{"csv":"version-001"},"publication":{"expected_revision":0,"idempotency_key":"build-team-skills-001"}}'

4. 查询图与精确版本上下文

curl -sS http://127.0.0.1:8000/graphs/retrieve \
  -H 'Content-Type: application/json' \
  -d '{"graph_id":"team-skills","task":{"id":"query-001","instruction":"清理并汇总 CSV 文件"},"limit":5}'

curl -sS http://127.0.0.1:8000/graphs/context \
  -H 'Content-Type: application/json' \
  -d '{"graph_id":"team-skills","task":{"id":"query-001","instruction":"清理并汇总 CSV 文件"},"limit":5,"budget":{"max_chars":20000,"skill_max_chars":8000}}'

错误与返回边界

状态码含义常见触发条件
404对象或本地源不存在Skill 引用、版本或服务端路径未找到。
409冲突Skill 版本冲突；图 revision 或幂等键冲突。
422输入无效字段校验失败、图来源不足、向量 profile 不兼容，或请求项目与绑定项目不一致。
501流程未配置或尚未实现默认本地服务的 management pipeline 为空；训练与演进流程也可能尚未实现。
502模型操作失败场景抽取、补全、关系推断或查询改写失败。
503服务范围或存储问题图路由未绑定项目，或图持久化失败。

图接口字段校验错误统一返回简短信息，不回显完整输入；图业务错误返回稳定类别。POST /graphs/published-result 找不到成功记录时返回 JSON null，不能据此断定后台操作已失败。
